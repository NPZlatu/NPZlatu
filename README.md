### How I work with AI

I work in an AI-native workflow every day. I plan the work and write the test strategy, Claude Code agents write the code and tests (often several in parallel, connected to databases, logs and tickets through MCP servers), a separate review agent and CodeRabbit challenge each change, and I verify the result end to end on staging before it ships. Nothing ships on an agent's word.

### Selected work

- **[RAGAS-LLM-Judge-Reliability-Study](https://github.com/NPZlatu/RAGAS-LLM-Judge-Reliability-Study)**: my Master's research. I tested an LLM evaluation tool itself: 3 judge models, 4 dataset variants, 1,800 scores. Changing the judge moves a score by about 0.1, the judges still rank systems in the same order, and one metric (Answer Relevancy) cannot detect hallucinated answers.
